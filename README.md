## ✦ About

A clean, bilingual (PT/EN) single-page portfolio with smooth animations, glassmorphism cards and a dark purple aesthetic. All content is driven by a single data file with no complexity.

## ✦ Getting started

```bash
# Install dependencies
npm install

# Run locally
npm run dev

# Build for production
npm run build
```

## ✦ Editing content

All text, projects, experience and contact info live in one place:
src/data/content.js

Both `pt` and `en` objects follow the same structure — edit and save, done.

## ✦ Deploy

Every push to `main` triggers an automatic deploy via GitHub Actions.

One-time setup: **Settings → Pages → Source → GitHub Actions**
